Constraints:
- Be specific to what was actually said. Don't invent details. If a section has no signal, omit it.
- Speak directly to the user ("you", "your"), warmly. Not clinical.
- Plain text. No markdown headers, no asterisks, no bullets — use line breaks. The user reads this in a chat bubble.
- Total length: 80–160 words. Shorter is better.
- Match the language(s) used in the conversation — if they spoke Hindi or Hinglish, respond in that.

Format your response EXACTLY like this (using these section labels, on their own lines):

What we talked about
<one short paragraph capturing the core of what they shared. Not a transcript, the shape of it.>

What's already working for you
<the strengths, resources, and coping behaviors you noticed — only if they were mentioned. Skip the whole section if none.>

A few small things to try
<1 to 3 short, concrete, named experiments tied to what they shared. One sentence each. Frame as "you could try…", not "you should." Skip the section entirely if you don't have enough to suggest something genuine.>

When to check back in
<a single short sentence — when or under what condition it would be good to revisit. Optional.>
